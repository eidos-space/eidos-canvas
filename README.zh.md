# Canvas 画布

在 Eidos Lite 的画布上整理笔记、链接和文件。Canvas 可以打开和保存 Obsidian 使用的 `.canvas` 文件。

## 打开第一张画布

1. 在 Eidos Lite 打开「插件 → 插件市场」，找到 **Canvas 画布**并安装，然后在要使用画布的 Space 中启用。
2. 选择「新建文件 → Canvas (.canvas)」创建空白画布。已有 `.canvas` 文件可以在 Space 目录树里右键选择「打开方式 → Canvas 画布」。

## 整理画布

- **添加卡片和分组。** 在底部工具栏选择工具，或按 **I** 打开插入菜单。**T**、**F**、**L**、**G** 分别对应文本、文件、链接和分组。点击画布即可放置卡片并就地编辑，分组可以拖框绘制。
- **移动、调整和连线。** 拖动卡片即可移动。选中卡片后，拖动卡片一角调整大小，或点「颜色」选择预设。连线时先选中起点卡片，按 **C**，再点击目标卡片。双击卡片或连线即可编辑。
- **浏览和保存。** 拖动画布背景可平移，在背景上滚动可缩放。按 **+** 或 **−** 缩放，按 **0** 查看完整画布。macOS 上按 **⌘S** 保存，Windows 和 Linux 上按 **Ctrl+S** 保存。

## 引用 Space 里的 Markdown

把 Markdown 文件从 Space 目录树拖到画布。卡片会预览原文，原文保存后预览也会刷新。点击卡片标题即可在 Eidos Lite 打开原文。

如果 Markdown 文件移动或改名，把它拖到显示文件不可用的卡片上即可恢复引用，并保留卡片的位置和连线。也可以点「重新关联」，输入文件在 Space 中的新路径。把画布移到另一个 Space 时，记得把引用的文件一起带上，以便继续预览。
